# SOIPOI — Jiangsu Suyuan Baiyi Trading Co., Ltd.

Overseas marketing site for **Jiangsu Suyuan Baiyi Trading Co., Ltd. (苏源百宜 / SOIPOI)**,
a vertically integrated yarn manufacturer and exporter based in Zhangjiagang, Jiangsu, China.

## Products
- Fancy yarn (花式纱)
- Core-spun yarn (包芯纱)
- Worsted yarn (精纺纱线)
- Knitted & woven fabrics (针织/梭织面料)

## Structure
- `index.html` — single-page marketing site (About / Yarns / Capabilities / Global Reach / Contact)
- `styles.css` — styling
- `script.js` — interactions + inquiry form (mailto fallback)
- `favicon.svg`, `robots.txt`, `sitemap.xml` — SEO & branding

## Deploy
Hosted on GitHub Pages. To point a custom domain (e.g. soipoi.com), add a `CNAME` file
and configure DNS.
